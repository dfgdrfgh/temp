# Standalone Prices Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Extract Firmament price tooltips into an independent Minecraft 26.2 Fabric client mod.
**Architecture:** Java translation of the original price and identity logic, immutable price snapshots, asynchronous network refreshes, Fabric tooltip/keymapping APIs. NEU metadata supplies the same stock and contextual identity mapping.
**Tech Stack:** Java 25, Fabric Loom 1.17, Gradle 9.5.1, Fabric API, Gson, JUnit.
**Spec:** docs/superpowers/specs/2026-10-29-prices-design.md

## Global Constraints
- Minecraft 26.2 Fabric only; no dependency on full Firmament.
- Keep original price semantics/defaults, item identification and licenses.
- Preserve default artifact filename and upload jar through Actions.

## Review Focus
- Bazaar buy/sell labels reverse the corresponding API fields in order mode.
- Logical sack/order counts differ from visible ItemStack count.
- Special IDs and Bazaar stock aliases must match NEU.
- Network failures must not erase good data or terminate refresh loops.
- 26.2 GUI and key mapping APIs changed from the fork's 26.1.2.

### Task 1: Price core and parity checks
- [ ] Add failing tests for order/instant semantics, Bazaar priority, averages, formatting and logical counts in src/test/java.
- [ ] Implement PriceLogic.java and run the checks.
### Task 2: Metadata, configuration and Fabric integration
- [ ] Translate item identity and contextual lookup; test special variants and NEU metadata.
- [ ] Add asynchronous price/metadata fetching with retained snapshots; test malformed/failed data.
- [ ] Add Fabric tooltip hook, key mappings and settings command with original defaults.
### Task 3: 26.2 packaging and verification
- [ ] Replace the root build with the extracted standalone mod and retain licenses.
- [ ] Run tests/build and a client launch smoke test; inspect packaged entrypoint and metadata.
- [ ] Push branch, verify Actions and provide the artifact run link.
